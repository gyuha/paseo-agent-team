# 팀 정의는 워크스페이스마다 하나씩, `.agents/teams/<오케스트레이터 워크스페이스>.json`에 둔다

ADR 261029-093300(팀 정의는 레포 안 `.agents/team.json` 하나)을 개정한다. 이제 한 프로젝트에 팀이 여러 개 있을 수 있다. 팀은 오케스트레이터가 도는 워크스페이스(`orchestrator.workspace`, 이름으로 매칭)에 속하고, 팀마다 파일 하나에 저장한다. 기존 `.agents/team.json`은 마이그레이션하지 않고 그대로 읽는다. 팀끼리는 워크스페이스(오케스트레이터 워크스페이스와 전용 역할 워크스페이스)를 함께 쓰지 않는다. 이렇게 해야 한 팀의 역할 세션이 다른 팀의 세션과 섞이지 않는다. 그래서 같은 팀을 여러 워크스페이스에 띄우던 "Start the team here"(task 9)는 없앴다.

**Considered Options**: 파일 하나에 `{ version: 2, teams: [...] }`로 담는 안은 버리고 파일을 나누는 안을 택했다. 버전 마이그레이션을 피하고, git diff와 충돌이 팀 단위로 나뉘며, 오케스트레이터가 자기 파일 하나만 읽으면 되기 때문이다.

**Consequences**: 워크스페이스 이름을 바꾸면 팀이 그 워크스페이스에서 떨어진다. 파일 이름은 처음 저장할 때 정해지고, 그 뒤에는 이름이 바뀌어도 따라가지 않는다.
