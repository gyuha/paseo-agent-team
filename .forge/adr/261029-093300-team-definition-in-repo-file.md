# 팀 정의는 플러그인 설정이 아니라 프로젝트 레포의 `.agents/team.json`에 둔다

paseo-bots는 봇/팀 정의를 플러그인 설정(Paseo 쪽, 레포 밖)에 저장하지만, 이 플러그인은 프로젝트 단위 오케스트레이션이므로 팀 정의를 해당 프로젝트 레포 안 `.agents/team.json`에 둔다. 이유: git으로 공유·이력 관리되고, 플러그인이 없어도 오케스트레이터 에이전트가 같은 파일을 읽을 수 있으며, workspace를 ID(`wks_…`, 기기 종속) 대신 이름(title)으로 참조해 clone한 다른 기기에서도 재사용된다. 대가: UI로만 편집하는 경험은 약해지고, 파일과 실제 workspace가 어긋날 수 있어 적용 시 이름 매칭으로 재조정해야 한다.
